# Парсер Instagram

Собирает объявления о продаже авто из Instagram-профилей.
Отдельная часть проекта на Python, к сайту (Next.js) отношения не имеет.

## Первый запуск

Все команды выполняются из папки `parser/`:

```bash
cd parser

# 1. Создать виртуальное окружение (один раз).
#    Это отдельная «коробка» с библиотеками только для парсера.
python3 -m venv .venv

# 2. Включить окружение (каждый раз в новом окне терминала).
#    В начале строки терминала появится (.venv).
source .venv/bin/activate

# 3. Установить библиотеки (один раз и после изменений requirements.txt).
pip install -r requirements.txt

# 4. Создать файл настроек (один раз) и при необходимости поправить его.
cp .env.example .env

# 5. Запустить
python main.py
```

Выключить окружение: `deactivate`.

> Если у вас активна conda (в терминале видно `(base)`), сначала выполните
> `conda deactivate`, чтобы окружение создалось от обычного Python.

## Файлы

| Файл | Зачем |
|---|---|
| `main.py` | сам парсер, точка входа |
| `requirements.txt` | список нужных библиотек |
| `.env.example` | образец настроек, лежит в git |
| `.env` | ваши настройки и пароли, **в git не попадает** |
| `.venv/` | виртуальное окружение, **в git не попадает** |
