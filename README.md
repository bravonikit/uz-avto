# Mashina — объявления о продаже авто в Узбекистане

Первая версия сайта: поиск, лента объявлений, страница машины и форма подачи объявления.
Работает на тестовых данных, без базы.

**Стек:** [Next.js 16](https://nextjs.org) + React 19 + TypeScript + Tailwind CSS 4.

## Как запустить у себя

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install     # один раз: скачать зависимости
npm run dev     # запустить сайт в режиме разработки
```

Откройте http://localhost:3000. Пока команда работает, сайт сам обновляется при сохранении файлов.
Остановить — `Ctrl + C` в терминале.

Другие команды:

```bash
npm run build   # собрать «боевую» версию (так же делает Vercel)
npm run start   # запустить собранную версию
npm run lint    # проверить код на ошибки
```

## Что где лежит

```
src/
  app/                    ← страницы: папка = адрес на сайте
    page.tsx              /            главная с поиском
    cars/page.tsx         /cars        лента с фильтрами
    cars/[id]/page.tsx    /cars/1001   страница объявления
    sell/                 /sell        форма «Подать объявление»
    layout.tsx            общий каркас (шапка, подвал)
  components/             куски интерфейса: карточка, поиск, галерея
  lib/
    listings.ts           тестовые объявления и поиск по ним
    catalog.ts            марки, модели, города
    format.ts             форматирование цен («155 000 000 сум») и дат
```

Чтобы добавить машину — допишите объект в `src/lib/listings.ts`.
Новую марку или город — в `src/lib/catalog.ts`.

## Как выложить на Vercel (бесплатно)

1. Загрузите проект на GitHub.
2. Зайдите на [vercel.com](https://vercel.com), войдите через GitHub.
3. **Add New → Project**, выберите репозиторий, нажмите **Deploy**. Настройки менять не нужно.

После этого каждый `git push` будет обновлять сайт автоматически.
