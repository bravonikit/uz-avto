# Uz Avto: статус проекта

Сайт объявлений о продаже авто для Узбекистана по типу auto.ru.
Обновлено: 12.11.2026

## Как устроено

* `src/` сайт на Next.js (TypeScript, Tailwind)
* `parser/` парсер Instagram на Python (gallery-dl, вход через куки Safari)
* Репозиторий: github.com/bravonikit/uz-avto
* Работаем ветками: `features/...` → PR → `main`
